# Product Roadmap

## Phase 2 — Premium Product Experience

- Complete unified design system
- Responsive desktop density controls
- Remove nested scrolling
- Compact AI panels
- Animated KPI transitions
- Premium loading, empty and error states
- Accessible keyboard navigation
- Consistent multilingual terminology
- Final visual polish for Formulations, Run Config and Excel Import

## Phase 3 — Fluidnatek Technical Copilot

Transform the current generic chat into a contextual technical copilot.

Planned capabilities:

- Automatically receive selected formulation and run context
- Compare the active run with similar historical experiments
- Explain instability causes
- Recommend the next controlled experiment
- Show confidence and evidence
- Identify missing data
- Generate action plans
- Produce structured answers:
  - diagnosis
  - recommended action
  - proposed parameters
  - scientific reasoning
  - risks
  - confidence
  - supporting experiments

## Phase 4 — Smart Memory

- Semantic experiment search
- Vector representations of formulations and runs
- Similarity retrieval
- Company-specific process memory
- Persisted learning in Firestore
- Confidence evolution over time
- Explainable recommendation evidence
- Human review and correction workflow

## Phase 5 — Autonomous Excel Ingestion

- Header-position-independent extraction
- Sheet-name-independent resolution
- Multi-template detection
- Automatic material matching
- Automatic formulation reconstruction
- Confidence-based decisions
- Human review only below confidence threshold
- Learned aliases persisted in Firestore
- Import report and rollback
- Idempotent imports
